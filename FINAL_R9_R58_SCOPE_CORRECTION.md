# EXP_R9–EXP_R58 scope correction

This note corrects the interpretation of the run range without deleting or
rewriting any original experiment report.

| Range | Count | What actually happened | How it should be cited |
|---|---:|---|---|
| `EXP_R9–EXP_R16` | 8 | Substantive latent-control method experiments with comparisons and held-out surrogate diagnostics | The actual method-iteration core |
| `EXP_R17–EXP_R58` | 42 | Stage-specific interface, data-availability, and feasibility gates; mostly `NOT_RUN_INTERFACE_GATE` | Blocked continuation audits, not new control methods |

The protocol therefore reached the administrative identifier `EXP_R58`, but it
did not complete the originally intended 50 rounds of new methods. The honest
scientific status is that method development stalled around `EXP_R16`, while
the remaining identifiers documented why the requested physical/causal
experiments could not be executed with the available data and interfaces.

No full physical closed-loop claim is supported. Future work must obtain the
missing causal simulator/controller snapshots and then register a new,
method-driven sequence; it must not relabel another set of feasibility checks
as additional method experiments. `EXP_R59` remains forbidden by the existing
protocol.

# Representation result catalog

- `data_integrity.json`: exact 31-episode compact-data audit.
- `development_validation/`: leave-one-episode-out selection evidence.
- `historical_gate/`: original confirmation decision and failed-cell
  forensics; the recorded decision remains `FAIL`.
- `independent_replication/`: 14-episode, six-seed frozen replication,
  machine-readable semantic/motor tables, bootstrap interval, and final
  readiness decision.
- `dynamics_preregistration.json`: equal-information-set requirements for the
  next stage.
- `representation_tests.xml`: machine-readable released-code test report.

The authoritative final status is
`independent_replication/representation_status.json`.
